# Forge3D v2.0.0 — Native Edition

Forge3D 2.0 is the Native Edition: the `f3dc` compiler is now
written in Fortran (plus a small clang C helper) with zero Python
anywhere in the repository, and the renderer gained smooth shading,
native PNG output, reusable model components, a smarter preview
server and a WebGL2 viewer by default.

A scene still takes three lines:

```f3d
scene size 640 480 background black
camera at 4 3 6 look 0 0 0
cube spinner red at 0 0 0
```

## Highlights

- **Smooth shading** — curved surfaces shade with true per-vertex
  normals in the Fortran engine, the Canvas2D player and the
  WebGL2 viewer (a default sphere: ~20 faceted bands before, 159
  distinct colours now). `shading flat` restores the faceted look.
- **Native PNG output** — `render to "shot.png"` and numbered
  animation frames are encoded by the engine itself. No more
  ImageMagick dependency for PNG.
- **Model components** — `import "parts/fin.f3d" as fin` reuses a
  part file exactly like a hand-written group, and the new
  `mirror x|y|z` object property reflects a part in place. See
  `examples/rocket-parts.f3d`.
- **`NO_COLOR` / `F3DC_DEBUG`** — the native compiler honours both
  environment conventions: no colour when `NO_COLOR` is set or
  stderr is not a TTY, and per-diagnostic debug lines with
  `F3DC_DEBUG`.
- **Preview v2** — `f3dc preview` recompiles when any dependency
  changes: imported parts (including nested), `load`ed OBJ/glTF
  models and material textures — not just the scene file.
- **WebGL2 by default** — generated HTML viewers boot the WebGL2
  renderer first and fall back to the Canvas2D player
  automatically; the picture is the same either way.

## Upgrade notes

- **No breaking changes.** Every 1.x scene compiles unchanged, and
  the strict golden render is byte-identical to the 1.x output.
- **PNG no longer needs ImageMagick.** `f3dc doctor` may still list
  `convert` as an optional tool, but nothing uses it anymore.
- **`NO_COLOR` and `F3DC_DEBUG` are now honoured** by the native
  compiler (the 1.x native binary ignored both). Scripts that
  captured diagnostics are unaffected when output is piped — it
  was and stays colour-free there.
- Building from source needs Flang 18 (`flang-new-18`) and
  clang 18: `make f3dc`. There is no Python requirement at build
  or run time.

## Help wanted: the last parity item

One feature-matrix item remains open: **C4, a real-device WebXR
session check**. The XR sidecar is fully tested headlessly with
mocks, but only a human with a headset (or an XR-capable Android
phone + Chrome) can confirm an immersive session end-to-end. The
repo ships a ready-made check page (`examples/xr-check.html`) and
5-minute instructions in `docs/XR-CHECK.md`. A successful run
takes Forge3D to 40/40.
